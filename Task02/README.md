Task 02 – Return by Reference and Its Dangers

Objective:
To demonstrate returning references from functions and understand dangling references, const references and returning values by copy.

Concepts Used:
- Return by Reference
- Return by Const Reference
- Return by Value
- Dangling References
- Arrays and Vectors
- Pointers and Indexes

Program:
Q2_ReturnByReference.cpp

Compiler:
GCC 16.2.0

Compilation:
g++ -std=c++17 -Wall -Wextra -Wreturn-local-addr Q2_ReturnByReference.cpp -o q2

Execution:
.\q2.exe

Complexity Analysis:
Finding the highest mark requires O(n) time and O(1) extra space for reference, pointer and index approaches.
